Here’s a compact diagram set for ARCore coordinates + camera setup + YUV frame flow:

ARCore world/camera convention (right-handed)

               +Y (up)
                ^
                |
                |
+X (right) ---- O ---->  (camera right)
               /
              /
      -Z (forward, into scene)

At session start, world origin is near the initial camera pose.
Camera "forward" direction is along -Z.

Camera setup + YUV frame flow

[Physical RGB Camera Sensor]
            |
            v
[Android Camera HAL: YUV_420_888 stream]
            |
            v
[ARCore Session.update()]
   -> motion tracking (IMU + vision)
   -> camera pose (Frame.getCamera().getPose())
   -> intrinsics (fx, fy, cx, cy)
   -> background texture (for rendering)
            |
            +--> [Frame.acquireCameraImage()]  (YUV_420_888)
            |          |
            |          +--> Plane 0: Y (luma)
            |          +--> Plane 1: U (chroma)
            |          +--> Plane 2: V (chroma)
            |                    |
            |                    v
            |            [YUV -> RGB conversion]
            |                    |
            |                    v
            |            [CV / ML / SLAM processing]
            |
            +--> [OpenGL render path]
                       |
                       v
             [Camera background + virtual objects]
